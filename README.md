# 📚 [FILEVAULT]

An open-access digital library for college students to view, read, and download academic resources—completely free with zero login required.

---

## 🌟 Key Features

- 🔓 **100% Free & Open Access:** No login, accounts, passwords, or subscriptions required.
- 📖 **In-Browser Viewing:** Open and read PDFs, notes, and writeups directly in your web browser.
- 📥 **Instant Downloads:** Download notes, assignments, and practical outputs with a single click.
- 📁 **Organized Directory:** Easily find resources categorized by course, subject, and semester.

---

## 📂 Available Resources

- 📝 **Lecture Notes:** Comprehensive class notes and study materials.
- 📋 **Assignments:** Solution sets, practice papers, and project briefs.
- 🧪 **Practicals & Writeups:** Lab manuals, experiment writeups, and codes.
- 💻 **Outputs:** Sample execution results and practical screenshots.

---

## 🛠️ Tech Stack

- **Frontend:** HTML
- **Styling:** CSS
- **PDF Viewer:** Browser Native Viewer
- **Hosting:** GitHub
- **Cloud:** Supabase
